## 3. 顺带修掉一个 CLI 缺陷

现象：不传 `--event-root` / `--artifact-root` 时，CLI 报
`FATAL ERR_INVALID_ARG_TYPE The "path" argument must be of type string. Received null`。

根因（`DEBUG=1` 打 stack 定位到 `workflow.js:95` 的 `path.dirname(eventRoot)`）：
```js
function arg(name, fallback = null) { ... }
...
eventRoot: arg("--event-root", undefined),
```
**显式传 `undefined` 会触发默认参数**，`arg()` 实际返回 `null`，
于是 `eventRoot=null` 绕过了解构默认值 → `path.dirname(null)` 抛错。
直接调用 `runPurchaseWorkflow` 不经过 CLI，所以一直正常，掩盖了这个问题。

修复（`agents/purchase-inventory/src/cli.js`）：改成 `arg("--event-root") ?? undefined`，
把「未提供」显式还原成 `undefined`，让 workflow 的默认值生效。
同时给 CLI 的 catch 加了 `DEBUG=1` 时打印 stack（诊断改进，默认关闭）。

**回归验证**：原失败场景 `exit=0` / `WAITING_HUMAN` / 6 事件 / `VERIFIED`；
`--evals` 11/11 通过；`node --check` 通过；产物按 runId 分目录。
