## 人工QC只需给出的业务判断

| 检查项 | 人工判断问题 |
|---|---|
| 商品真实性 | 和实物是否一致？颜色、花瓣、绳结、扣件、配件有没有错？无法确认时标待确认 |
| 售卖对象 | 第一眼能否看出卖的是挂件？是否可能误以为包含包或其他道具？ |
| 主图表现 | 缩小后花朵/笑脸及整套挂件是否易辨认，主体是否突出，画面是否干净？ |
| 店铺定位 | 是否符合希望呈现的风格与质感，是否存在明显廉价感或不协调？ |
| 最终放行 | 愿不愿意把它放在该商品第一张？回答通过/不通过/待确认即可 |

用户不需要提供设计解决方案，反馈“主体小、字太多、像卖包、风格不对”等即可；也可直接否决，不必证明所有缺陷。

文件格式、解码/尺寸、英文、已知事实核对及商品结构初筛由助手先完成；平台硬性规格由助手核验后再提交，不能交由用户代查。具体平台规则仍待验证，以上不是平台官方规定。
