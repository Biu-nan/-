## 关键发现
- 旧配置只有8槽位，当前锁定方案是10槽位。
- 当前SKU9图会被旧输入器截为8图，其中仅7份不同图像内容。
- 旧输入器把市场报告、SEO及Listing文本混入资料原文；不能全作为商品事实。
- 旧QC降级分支只查sku/shot/text，却把尺寸、保真等其他项目直接置PASS；不能直接沿用。
- 已有图片信息读取和基础尺寸判定可作为优先复用候选。
- 当前图为1254×1254、1877933字节；本次没有强制1536×1536，也没有声称满足平台规格。
- 棕色绳圈与绿色绕结发生变化，触发产品身份门禁；英文未发现拼写错误不能抵消结构失真。
