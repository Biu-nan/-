# Google Ads SEO Keyword Research Prompt

你现在是一位拥有 10 年经验的北美跨境电商 SEO 专家与 Google Ads 资深投手。

请深度识别本对话中已经上传的产品图片，并结合本对话已经完成的产品识别、市场调研、VOC 和视觉规划信息，针对欧美市场，尤其是美国市场，联网检索并构建一个结构化的 Google Ads 投放词库。

请用 Markdown 表格输出，必须严格包含以下 4 个维度：

1. 核心大词 (Head Keywords)：搜索量较大但竞争激烈的品类词，建议词组匹配。
2. 精准长尾词 (Long-Tail Keywords)：包含具体属性、材质、尺寸、功能或使用对象的高购买意向词，建议完全匹配。
3. 场景与痛点词 (Scenario & Pain-point Keywords)：买家在特定节日、特定场景或为解决特定问题时搜索的词。
4. 核心否定词 (Negative Keywords)：容易产生误点击、耗费预算但不会转化的词，包括不相关品类、错误用途、错误材质、竞品品牌名和免费资源意图。

要求：

- 每个类别至少提供 8 个纯英文关键词。
- 所有关键词必须与当前商品高度相关。
- 先通过联网搜索验证真实市场用词，不要只凭主观想象。
- 如果无法获得真实 Google Ads 搜索量、曝光量和转化率，不得编造数值或声称为实测高转化数据；请使用搜索可见性、商业购买意图、平台重复出现频次和 Listing 使用频次作为代理信号，并明确说明。
- 不得把竞品品牌写入正向关键词。
- 不得把无法从产品图或对话确认的材质、尺寸、重量、套装数量写成当前商品事实。
- 无法确认的属性必须标记为“不确定 / 待人工确认”，不要硬塞进精准关键词。
- 除关键词表外，请补充：
  - Recommended Primary Keyword
  - Recommended Secondary Keywords
  - High-Intent Keyword Cluster
  - Seasonal Keyword Cluster
  - Negative Keyword Strategy
  - Keyword Risks / Need Confirmation
- 当前任务只输出关键词研究，不生成标题、详情页或图片。

成功概率：90%。
风险与后果：极度标准化，可能缺乏针对该产品独有特性的“神来之笔”。
长远影响：建立标准化拓词 SOP，可用于 Google Ads 基础广告组。
