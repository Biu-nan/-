## 2. 实际确认的店小秘页面导航路径及导出按钮（2026-10-11 只读实测）

| 功能 | 真实 URL | 关键控件 |
|---|---|---|
| 仓库清单 | `/web/warehouse/warehouseProduct` | 「导入/导出」「自定导出」；列头：商品信息/仓库位置/货架位/库存情况(安全 在途 未发 占用 可用 总量)/单价/总价/时间 |
| 商品管理 | `/web/dxmCommodityProduct/index` | 「导入/导出」「自定导出」；列头：图片/商品信息（+展开）/参考价/重量/尺寸/状态/时间 |
| 出入记录 | `/web/privateWarehouse/entryAndExitRecordList` | 页签「120天内记录」；时间组 = 全部/今天/昨天/7天以内/30天以内/**自定义**；`批量出/入库导出记录`；**明细行含「流水号 + 来源单号」** |
| 采购订单 | `/web/purchasing/order/waitAudit`（待审核）`/waitArrival`（待到货）`/draft/manualPurchasing`（草稿·手动）`/draft/aliPurchasing`（草稿·1688）`/complete`（已完成）`/cancel`（已取消） | 页签是 **URL 导航**（非点击）；搜索类型含 采购单号/SKU/运单号/关联订单号；创建时间 全部/今天/昨天/3天/7天/30天/自定义 |
| 采购跟单（SKU级缺货/在途） | `/web/purchasingFollow/list` | 列头含 缺货量/在途量/采购单号/待到货/运单号/采购员 |
| 供货商 | `/web/supply/supplier` | 页签 普通供货商 / 1688供货商；列头 供货商名称/结算方式/延时率/补货率/退货率/换货率/次品率/供货时效/时间 |
| 供货关系 | `/web/supply/supplyRelation` | 页签 供货商关系 / 商品SKU关系；列头 供货商名称/供货商品数/采购次数/…/最近交易时间 |

**采集策略**：沿用确定性最高的 **vxe-table DOM 跨页累计**（原生「导入/导出」是异步任务中心，盲驱动不稳）。

**关键发现（实测值）**：出入记录「时间=全部」返回 **17943 条**（120 天）；默认 7 天约 973 条。
35 天窗口实测 5800 行扫描 → 窗口内 **5725 行，覆盖 35 个自然日**。
